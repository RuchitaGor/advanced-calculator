# 🧮 Advanced Calculator

An interactive web-based calculator built using HTML5, CSS3, and JavaScript. It supports basic arithmetic operations, percentage calculations, memory functions, and calculation history.

## 📌 About the Project

The Advanced Calculator is designed to perform mathematical calculations through a simple and user-friendly keypad interface. It includes additional features such as memory operations, decimal handling, sign toggling, and a history of the last five calculation results.

## ✨ Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Decimal number support.
- Plus/minus toggle to change the sign of a number.
- Percentage calculations.
- Memory functions:
  - **M+** – Add the current value to memory.
  - **M-** – Subtract the current value from memory.
  - **MR** – Recall the stored memory value.
  - **MC** – Clear the stored memory.
- Prevents multiple decimal points in a single number.
- Displays "Cannot divide by zero" when division by zero is attempted.
- Displays the last five calculation results.
- Interactive calculator keypad.
- Clear button to reset the current calculation.

## 🛠️ Technologies Used

- **HTML5:** Used to create the structure and calculator elements.
- **CSS3:** Used for styling, layout, colours, buttons, and display design.
- **JavaScript (ES6):** Used to implement calculator logic, arithmetic operations, memory functions, input validation, and calculation history.

## ⚙️ Methods and Concepts Used

### JavaScript Concepts

- **Functions:** Separate functions for addition, subtraction, multiplication, and division.
- **Switch Statement:** Selects the arithmetic operation based on the selected operator.
- **Conditional Statements (if-else):** Handle input validation and error conditions.
- **Event Handling:** Responds to calculator button clicks.
- **DOM Manipulation:** Dynamically updates the calculator display and calculation history.
- **Arrays:** Store and display the last five calculation results.
- **Variables and Operators:** Manage calculations, current input, and memory values.

### Input Validation and Error Handling

- Prevents multiple decimal points in a single number.
- Handles division-by-zero errors.
- Validates calculator inputs before performing operations.

### Memory Management

- **M+:** Adds the current value to stored memory.
- **M-:** Subtracts the current value from stored memory.
- **MR:** Retrieves the stored memory value.
- **MC:** Clears the stored memory.
